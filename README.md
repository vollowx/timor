# Timor

A web clock app with clock, stopwatch, and timer. Written with
[Lit](https://lit.dev) and [@vollowx/seele](https://tideover.cc/seele/).

## Getting started

```bash
pnpm install
pnpm run dev
pnpm run build
pnpm run preview
```
